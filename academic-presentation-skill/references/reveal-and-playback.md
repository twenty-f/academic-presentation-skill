# 逐击设计与放映核验

设计动画由讲解需要决定。先写下初始画面、每次点击新增或强调的对象，以及最终画面应该保留的线索。维持上一段讲过的视觉锚点，避免让观众重新找位置。需要比较多个动画版本时，先选一页代表性内容试做。

| 核验环节 | 应检查的证据 |
| --- | --- |
| 文件结构 | 实际演示稿中存在可编辑元素、备注和所需动画对象，页序、对象标识和媒体引用可回查。 |
| 静态预览 | 在实际输出的画面中检查尺寸、位置、投影可读性、遮挡、溢出及字体替代。 |
| 点击序列 | 按预定顺序检查初态、关键中间态和末态，确认被讲到的内容在正确时点出现。把软件模拟写作模拟。 |
| 目标软件实播 | 记录软件、版本、起始页和点击步骤，复核实际出现的对象与顺序。某页异常时，以同一文件和点击路径重现，再复测修订稿。 |

能力有限时，把需要依次讲的内容拆成连续静态页，或用同页编号交代顺序。即使动画未实测，保持静态导出的每个必要结论都有完整的证据和口径。交付记录可以保留「尚未在目标软件实播」等具体缺口。
